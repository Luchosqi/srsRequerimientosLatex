\chapter*{Instrucciones para el uso de este formato}
\addcontentsline{toc}{chapter}{Instrucciones para el uso de este formato}

Este formato es una plantilla para documentos de requisitos de software. Está basado y es conforme con el estándar IEEE Std 830-1998. Las secciones que no se consideren aplicables al sistema descrito podrán indicarse justificadamente como no aplicables (NA).

Los textos de orientación deben eliminarse y, cuando corresponda, sustituirse por el contenido descrito en cada apartado. Los textos entre corchetes, como \campo{Inserte aquí el texto}, señalan campos que deben completarse.

Los títulos y subtítulos están organizados jerárquicamente. La numeración y el índice se generan automáticamente mediante LaTeX. Al terminar la redacción, compile el documento dos veces para actualizar las referencias y la tabla de contenido.
